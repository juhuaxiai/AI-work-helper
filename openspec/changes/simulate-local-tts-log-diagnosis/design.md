## Context

当前诊断图规划并调用 MCP `SearchLog`，解析 `LogJson` 后保存日志证据和来源。测试可以通过独立项目配置把现有客户端指向临时启动的本地服务。

## Goals / Non-Goals

目标是用一次可重复的离线集成测试验证本地日志到报告的链路。正式的本地观测源配置和工作台演示入口属于后续变更。

## Decisions

- 回环 HTTP 测试端点承担 TTS 排队场景。它实际等待，记录实测排队时间、请求 ID、时间戳和 `environment=test`，并追加到本次执行的临时 JSONL 文件。脚本检查延迟阈值后构造告警输入。
- 同一临时监听器注册真实 MCP `SearchLog`。数据来自固定的本次测试文件，按测试日志主题、请求时间窗口和结果条数筛选，再用现有诊断图能识别的格式返回。
- FastAPI 通过诊断 API 入队并执行真实诊断图，SQLite 保存任务、证据和报告。使用现有测试模型能力触发确定性回退报告。测试结束时关闭监听器，数据库和日志留在 pytest 临时目录。部署无需迁移。

## Risks / Trade-offs

- 现有诊断图按 CLS 的参数形状发起查询，时间窗口内的文件需要专用于本次演示，避免把不同测试的证据混在一起。
- 回退报告可以证明日志被引用。模型生成质量和真实告警平台推送需要各自的验收场景。
