## Context

个人会话、文档和向量目前按账号 ID 查询。组织目录已经可以由当前账号解析企业和本部门权限。

## Decisions

- 给新会话持久化当前企业，所有会话操作保留所有者过滤并校验企业。已有个人会话保持个人范围。
- 企业共享库与运维 SOP 使用不同的稳定数据范围。后端根据组织身份计算可访问范围。企业成员可读取共享库，本部门负责共享库和 SOP 的维护。新诊断案例单独存放在受限知识库。
- RAG 的向量和关键词召回按服务端范围分别查询，在排序前复核每条记录的作用域。普通聊天使用知识、时间和已选 Skill 工具。

## Risks / Trade-offs

已有个人知识的原归属保留。生成的旧诊断案例仍保存在数据库，普通知识入口和检索会过滤这些资料。
