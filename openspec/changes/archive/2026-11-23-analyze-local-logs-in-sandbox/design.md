## Context

日志快照最多 500 条和 128 KiB。现有审批沙箱拥有独立 Docker Worker。离线统计没有环境访问权限，值班员显式请求即可执行。

## Decisions

- 使用固定 `tts-log-statistics` 模板、固定镜像 ID、同一隔离配额。快照通过标准输入提供，不创建宿主挂载或注入凭据。
- 每个文件引用至多一个统计任务。与现有执行 Worker 共用 durable runtime；读取快照及回写前检查租约、取消、有效期和当前权限。
- 输出仅包含合法记录计数、无效行计数及各阶段的均值、P95、最大耗时。以稳定 ID 保存证据并关联既有报告。

## Testing

- 通过本地测试服务生成实际日志，在 Docker 中统计，验证证据、跨部门限制、幂等、过期和容器清理。
